# RoboDistro Electron App

A cross-platform desktop app for high-performance media distribution using robocopy. Features:
- Select local source directory (native picker)
- Enter UNC target path
- Display and run robocopy command
- Show live output
- Remember last used paths

## Getting Started

1. Install dependencies:
   npm install
2. Run the app:
   npm start

## Project Structure
- main.js: Electron main process (backend, process management)
- renderer/: Frontend UI (HTML/JS/CSS)
- package.json: Project metadata and scripts

## Platform
- Windows-optimized, but cross-platform
